Operations server not reachable

This dashboard stores orders in the shop's private database, so shared multi-user data needs the LEPAKSHI WEAVES server (server.py) to be running.

The public website on Vercel is static and does not run the Python server. For shared production use, open the dashboard from the computer or host where python server.py runs (for example http://localhost:8080/ops.html).
