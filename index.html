Janardan Textiles — Full-Stack Guide & AI Catalogue Prompt

1. Running the Python + SQLite REST Backend (`server.py`)

Start the backend server with python server.py (serves on http://localhost:8080). All products, 6-view galleries, uploaded images (saved to /assets/uploads/), demo orders, stock deductions, wholesale enquiries, contact messages, and settings are persisted in janardan_textiles.db.

2. REST API Endpoints (`server.py`)

  • GET /api/health & GET /api/bootstrap — Load persisted SQLite state
  • POST /api/seed & POST /api/reset-demo — Seed or reset database
  • PUT /api/products/:id & POST /api/products — Update or create saree
  • PUT /api/products/:id/gallery/:viewIdx — Upload/update any of the 6 views
  • POST /api/orders & PATCH /api/orders/:orderId — Create order (auto-deducts stock) & update status
  • POST /api/wholesale & PATCH /api/wholesale/:enquiryId — Save & update B2B wholesale leads
  • POST /api/contact & PATCH /api/contact/:messageId — Save & manage customer messages
  • PUT /api/settings/contacts & PUT /api/settings/policies — Update contacts & policies

3. Master 6-Image Photorealistic Saree Catalogue Prompt

This exact prompt template is also built into the Admin → AI 6-Image Studio tab so you can auto-fill it for any saree or generate all 6 views directly:

Create six separate, high-resolution, photorealistic fashion product images of this exact same saree for an online catalogue.

SAREE DETAILS
- Name: [name]
- Fabric: [fabric]
- Main color: [color]
- Border and zari: [describe exactly]
- Motifs: [describe exactly]
- Blouse piece: [describe exactly]
- Occasion: [occasion]

Keep the color, fabric, pattern, border and blouse identical in all six images. Use the same adult Indian model, lighting and calm studio background wherever the model appears. Do not let jewelry, hands or props hide the saree.

Image 1: Full front view, model wearing the saree, full drape visible.
Image 2: Back view showing the fall and complete pallu.
Image 3: Close view of the border and zari, sharp focus.
Image 4: Macro close-up of the fabric weave.
Image 5: Matching blouse piece shown clearly with the saree.
Image 6: Full-length occasion styling, complete look visible.

No text, price labels, logos, watermarks, frames or extra garments. Do not change the saree design between images.
